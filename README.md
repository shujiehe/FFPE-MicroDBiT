# FFPE Spatial Transcriptomics

This repository contains scripts for data processing, downstream analysis, and visualization of host and microbial spatial transcriptomics data from formalin-fixed paraffin-embedded (FFPE) tissue sections.

## Overview

The scripts support the analysis of spatially resolved host gene expression and microbial distributions within FFPE tissue sections, including the characterization of host and microbial features and their spatial relationships.

## Repository Structure

- **Data_processing/**  
  Scripts for sequencing data processing, taxonomic classification, and spatial expression matrix generation.

- **Data_analysis/**  
  Scripts for downstream computational and statistical analyses of host and microbial spatial transcriptomics data.

- **Visualization/**  
  Scripts for generating figures and visualizing spatial expression patterns and analysis results.

## Usage

Scripts can be executed independently or as part of the relevant analysis workflows. Users should update the input/output paths and parameters according to their datasets.

Required input data, reference files, and software dependencies vary among scripts.

## Notes

The scripts are provided to facilitate reproducibility and adaptation of the analyses. Additional preprocessing steps or intermediate data may be required depending on the workflow.
